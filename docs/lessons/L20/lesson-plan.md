# L20　兩點之間與點到直線的距離（新課講授）

> 課型：**新課講授**｜第 20 節／全章 24 節｜教材範圍：1.2.5 兩點距離與點到直線的距離（PDF 第 53–57 頁）。學生表現一律為「預期情況」，實際請依課堂證據調整。

## A. 課堂基本資料

- 年級：高中選修（相當於中五）
- 課題：兩點之間與點到直線的距離
- 課時：40分鐘
- 課型：新課講授
- 核心學習目標：能用向量求兩點距離，並用設參數或投影的方法求點到直線的距離
- 先備知識：L02 長度公式、L07 距離公式、L11 用參數設點
- 教學重點：空間距離都是「最短連線」；點到直線的距離要找垂足
- 學習難點：棱不垂直時用基底展開；設參數找垂足
- 本節刻意不教：點到平面的距離（L21）

### 第 1 階段　0–5 分鐘　課堂安頓＋分層起步題（簡報：熱身挑戰：先動手算一算；螺旋：舊概念）

## D. 典型錯誤分析

以下均為「預期錯誤」（未取自真實學生作答），教師可換成當堂收集、去識別化的例子。

### 5-1 抓錯偵探：斜棱也能這樣算？

- 題目：單位基底兩兩夾角 60°，求 \(|\boldsymbol{a}+\boldsymbol{b}+\boldsymbol{c}|\)。
- 錯誤示例：\(|\boldsymbol{a}+\boldsymbol{b}+\boldsymbol{c}|^2=1+1+1\) → 長度 \(\sqrt3\)（錯在第 1 步）
- 可能原因：程序錯誤：斜棱不垂直，漏了 \(2(\tfrac12+\tfrac12+\tfrac12)=3\)。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：\(|\cdots|^2=6\)，長度 \(\sqrt6\)
- 修正後練習：直線過 (1,0,0)、方向 (0,1,0)，點 P(1,3,4) 到直線的距離？

### 5-2 再抓一次：這是點線距離嗎？

- 題目：棱長 1 的正方體，求 C₁ 到直線 BD₁ 的距離。
- 錯誤示例：連接 C₁B → 距離是 \(C_1B=\sqrt2\)（錯在第 1 步）
- 可能原因：概念錯誤：C₁B 不垂直 BD₁，不是垂線段。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：找垂足：\(\lambda=\tfrac23\)，距離 \(\dfrac{\sqrt6}{3}\)
- 修正後練習：直線過 (1,0,0)、方向 (0,1,0)，點 P(1,3,4) 到直線的距離？

## E. 出口題及評估

### 2. 螺旋深化路徑

- 學生已經理解：平面內學過點與點、點與直線的距離；空間中會用距離公式。
- 本次新增的理解：所有距離都可以歸結為「最短連線的長度」；棱不垂直時也能用基底算；點到直線的垂足可由數量積為 0 求得。
- 之後會延伸到：L21 點到平面；L22、L23 綜合。
