# L22　空間距離綜合練習（練習課）

> 課型：**練習課**｜第 22 節／全章 24 節｜教材範圍：1.2.5 距離綜合練習（PDF 第 60–63 頁）。學生表現一律為「預期情況」，實際請依課堂證據調整。

## A. 課堂基本資料

- 年級：高中選修（相當於中五）
- 課題：空間距離綜合練習
- 課時：40分鐘
- 課型：練習課
- 核心學習目標：能分辨距離的類型，選用合適公式獨立求出兩點、點線、點面及平行距離
- 先備知識：L11、L20、L21
- 教學重點：判斷距離類型，全部歸結為點線或點面距離
- 學習難點：選平面內合適的點；證明平行後才求距離
- 本節刻意不教：全章綜合題（L23、L24）

### 第 1 階段　0–6 分鐘　診斷起步題（簡報：暖身診斷：你在哪一關？；螺旋：基礎辨識）

- 教師活動：展示目標；用三道快問診斷學生在哪一關。
- 學生活動：獨立判斷並用手勢作答。
- 教學資源：互動簡報 1-1 今天的目標、1-2 診斷快問、1-3 診斷二：點線、1-4 診斷三：點面；學習單（handout.html）。
- 理解檢查：A(1,1,1)、B(2,3,3) 的距離是？；求點到直線的距離，關鍵條件是？；\(\overrightarrow{BA}=(0,2,-2)\)，\(\boldsymbol{n}=(1,0,1)\)，距離是？
- 可能困難（預期情況）：程序錯誤：忘了開方；程序錯誤：把差相加；概念錯誤：平行就沒有交點
- 應對策略：先提示、後答案（重讀題目→相關概念→部分線索→關鍵步驟→必要時示範後換相近題再試）；票數超過三成選錯時，退回本階段前一頁重講。
- 支援提示：基礎薄弱：診斷結果只作選層依據。

### 第 2 階段　6–11 分鐘　方法回顧與關鍵步驟（簡報：解題秘笈大公開；螺旋：基礎辨識（方法與檢查））

- 教師活動：回顧方法與關鍵檢查步驟，只補診斷題暴露的缺口。
- 學生活動：說出每一步的理由，自我檢查。
- 教學資源：互動簡報 2-1 解題秘笈、2-2 自我檢查、2-3 秘笈二：選哪一點、2-4 代入檢驗；學習單（handout.html）。
- 理解檢查：求直線與平面的距離，首先要？
- 可能困難（預期情況）：程序上不需要；概念錯誤：直線沒有長度
- 應對策略：先提示、後答案（重讀題目→相關概念→部分線索→關鍵步驟→必要時示範後換相近題再試）；票數超過三成選錯時，退回本階段前一頁重講。

### 第 3 階段　11–25 分鐘　分層練習兩輪＋巡視（簡報：兩輪闖關：基本功到變化題；螺旋：獨立應用 → 變式比較）

## D. 典型錯誤分析

以下均為「預期錯誤」（未取自真實學生作答），教師可換成當堂收集、去識別化的例子。

### 4-1 抓錯偵探：平行了嗎？

- 題目：直線方向 \((1,1,0)\)，平面法向量 \((1,0,1)\)，求直線到平面的距離。
- 錯誤示例：取兩點，代公式 → 得到距離（錯在第 1 步）
- 可能原因：概念錯誤：\((1,1,0)\cdot(1,0,1)=1\neq0\)，直線與平面不平行，會相交。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：先驗證平行；這裏相交，距離是 0
- 修正後練習：原點換成 (1,1,1)，距離變成？

### 4-2 再抓一次：絕對值

- 題目：\(\overrightarrow{BA}\cdot\boldsymbol{n}=-3\)，\(|\boldsymbol{n}|=3\)，求距離。
- 錯誤示例：\(d=\dfrac{-3}{3}\) → \(d=-1\)（錯在第 1 步）
- 可能原因：粗心失誤：漏了絕對值，距離不可能是負數。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：\(d=1\)
- 修正後練習：原點換成 (1,1,1)，距離變成？
