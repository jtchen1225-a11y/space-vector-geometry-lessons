# L08　坐標運算與建系綜合練習（練習課）

> 課型：**練習課**｜第 8 節／全章 24 節｜教材範圍：1.1.3 坐標運算與建系（PDF 第 25–26 頁）。學生表現一律為「預期情況」，實際請依課堂證據調整。

## A. 課堂基本資料

- 年級：高中選修（相當於中五）
- 課題：坐標運算與建系綜合練習
- 課時：40分鐘
- 課型：練習課
- 核心學習目標：能獨立完成「建系→寫點→求向量→計算」的流程，解決夾角、長度、垂直問題
- 先備知識：L06 坐標運算、L07 建系與距離公式
- 教學重點：建系的選擇；由點到向量到結果的完整流程
- 學習難點：含參數的存在性問題；不同立體圖的建系
- 本節刻意不教：方向向量與法向量的名稱（L10、L12 才正式引入）

### 第 1 階段　0–6 分鐘　診斷起步題（簡報：暖身診斷：你在哪一關？；螺旋：基礎辨識）

- 教師活動：展示目標；用三道快問診斷學生在哪一關。
- 學生活動：獨立判斷並用手勢作答。
- 教學資源：互動簡報 1-1 今天的目標、1-2 診斷快問、1-3 診斷二：夾角、1-4 診斷三：垂直；學習單（handout.html）。
- 理解檢查：棱長 2 的正方體，D 為原點，AB 中點的坐標是？；\((1,0,1)\) 與 \((1,1,0)\) 夾角的餘弦是？；\((1,2,t)\perp(2,-1,3)\)，\(t\)＝？
- 可能困難（預期情況）：概念錯誤：x、y 對調；概念錯誤：這是 A₁B₁ 的中點；程序錯誤：只算了數量積
- 應對策略：先提示、後答案（重讀題目→相關概念→部分線索→關鍵步驟→必要時示範後換相近題再試）；票數超過三成選錯時，退回本階段前一頁重講。
- 支援提示：基礎薄弱：診斷結果只作選層依據。

### 第 2 階段　6–11 分鐘　方法回顧與關鍵步驟（簡報：解題秘笈大公開；螺旋：基礎辨識（方法與檢查））

- 教學資源：互動簡報 2-1 解題秘笈、2-2 自我檢查、2-3 秘笈二：換原點、2-4 代入檢驗；學習單（handout.html）。
- 理解檢查：平行六面體（棱互相不垂直）可以直接用三條棱作坐標軸嗎？
- 可能困難（預期情況）：概念錯誤：等長不代表垂直；概念錯誤：非正交基底有中間項
- 應對策略：先提示、後答案（重讀題目→相關概念→部分線索→關鍵步驟→必要時示範後換相近題再試）；票數超過三成選錯時，退回本階段前一頁重講。

## D. 典型錯誤分析

以下均為「預期錯誤」（未取自真實學生作答），教師可換成當堂收集、去識別化的例子。

### 4-1 抓錯偵探：可以這樣建系嗎？

- 題目：斜三棱柱，要求 AB₁ 長，以 A 為原點，三條棱為軸。
- 錯誤示例：B₁ 的坐標是棱長的組合 → 用距離公式開方（錯在第 1 步）
- 可能原因：概念錯誤：棱不垂直時，不能直接把棱長當坐標。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：改用基底展開，或另找兩兩垂直的三條線再建系
- 修正後練習：把棱長改成 1，3-1 B 層的餘弦會變嗎？為甚麼？

### 4-2 再抓一次：夾角公式

- 題目：\(\boldsymbol{a}=(1,2,2)\)，\(\boldsymbol{b}=(2,0,0)\)，求夾角的餘弦。
- 錯誤示例：\(\boldsymbol{a}\cdot\boldsymbol{b}=2\) → \(\cos\theta=\dfrac{2}{3}\)（錯在第 2 步）
- 可能原因：程序錯誤：分母只除了 \(|\boldsymbol{a}|\)，漏了 \(|\boldsymbol{b}|=2\)。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：\(\cos\theta=\dfrac{2}{3\times2}=\dfrac13\)
- 修正後練習：把棱長改成 1，3-1 B 層的餘弦會變嗎？為甚麼？
