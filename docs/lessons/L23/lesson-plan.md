# L23　角與距離單元複習（複習課）

> 課型：**複習課**｜第 23 節／全章 24 節｜教材範圍：1.2 空間向量在立體幾何中的應用 單元複習（PDF 第 60–63 頁）。學生表現一律為「預期情況」，實際請依課堂證據調整。

## A. 課堂基本資料

- 年級：高中選修（相當於中五）
- 課題：角與距離單元複習
- 課時：40分鐘
- 課型：複習課
- 核心學習目標：能把線線角、線面角、面面角與各種距離放進一張表，並在新情境中選用
- 先備知識：L10–L22
- 教學重點：所有問題都是：寫向量（方向或法向量）→ 代入一條公式
- 學習難點：在沒有提示公式的情況下辨認問題類型
- 本節刻意不教：全章綜合與幾何法比較（L24）

### 第 1 階段　0–5 分鐘　複習目標＋概念提取（簡報：熱身快問：你還記得多少？；螺旋：概念提取）

- 學生活動：不看筆記作答。
- 教學資源：互動簡報 1-1 今天的目標、1-2 快問快答、1-3 快問二：距離、1-4 快問三：法向量；學習單（handout.html）。
- 理解檢查：哪一種角要用正弦？；點面距離的公式是？；求平面法向量要幾條方程？
- 可能困難（預期情況）：概念錯誤：用餘弦；概念錯誤：用餘弦；概念錯誤：BA 不一定垂直平面
- 應對策略：先提示、後答案（重讀題目→相關概念→部分線索→關鍵步驟→必要時示範後換相近題再試）；票數超過三成選錯時，退回本階段前一頁重講。
- 支援提示：疲累或注意力不足：快問低壓力。

### 第 2 階段　5–12 分鐘　錯誤診斷（簡報：陷阱大搜查：錯在哪裏？；螺旋：錯誤診斷）

- 學生活動：找錯、辯論誰對。
- 教學資源：互動簡報 2-1 抓錯偵探、2-2 再抓一次、2-3 誰是對的？、2-4 哪個向量？；學習單（handout.html）。
- 理解檢查：甲：法向量夾角就是二面角。乙：相等或互補。；求平面 PBC 與底面所成的角，要？
- 可能困難（預期情況）：概念錯誤：反向後會變；概念錯誤：乙的說法正確；概念錯誤：這是線面角；概念錯誤：線面角用正弦。；粗心失誤：漏了絕對值。
- 應對策略：先提示、後答案（重讀題目→相關概念→部分線索→關鍵步驟→必要時示範後換相近題再試）；票數超過三成選錯時，退回本階段前一頁重講。

## D. 典型錯誤分析

以下均為「預期錯誤」（未取自真實學生作答），教師可換成當堂收集、去識別化的例子。

### 2-1 抓錯偵探：公式用錯了

- 題目：棱長 1 的正方體，求 AC₁ 與平面 AB₁C 所成角。
- 錯誤示例：\(|\cos\langle\boldsymbol{v},\boldsymbol{n}\rangle|=\tfrac13\) → \(\cos\theta=\tfrac13\)（錯在第 2 步）
- 可能原因：概念錯誤：線面角用正弦。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：\(\sin\theta=\tfrac13\)
- 修正後練習：天線與地面所成的角？

### 2-2 再抓一次：距離怎會是負的？

- 題目：\(\overrightarrow{BA}\cdot\boldsymbol{n}=-4\)，\(|\boldsymbol{n}|=2\)，求點面距離。
- 錯誤示例：\(d=\dfrac{-4}{2}\) → \(d=-2\)（錯在第 1 步）
- 可能原因：粗心失誤：漏了絕對值。
- 診斷問題：這個解法哪一步開始出現問題？為甚麼這樣計算不正確？怎樣檢查答案是否合理？
- 教師引導方式：不公開學生身份；先讓學生指出步驟，再追問成因，最後由學生修正。
- 正確做法：\(d=2\)
- 修正後練習：天線與地面所成的角？
